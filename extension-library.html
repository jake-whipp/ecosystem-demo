Code Walkthrough Assistant

libraryv1.6.2 buildpassing library apiv2.1 support#dev-experience

Code Walkthrough Assistant turns tribal knowledge into guided, interactive tours of a codebase. Authors record a walkthrough once. Readers step through it line by line, right inside VS Code, with explanations anchored to the exact code that matters.

Features

  • Guided tours: step through a codebase file by file, with each stop highlighting the lines that matter.
  • Record in minutes: select some code, write a note, press Enter. Tours are saved to .walkthroughs/ and versioned with the repo.
  • Refactor-proof anchors: steps are pinned to symbols rather than line numbers, so tours survive renames and moves.
  • Onboarding paths: chain tours into learning paths for new starters and see who has completed them.
  • Built on the Extension Library API: uses the shared library.identity and library.repos services, so there is nothing to configure.

Getting Started

  1. Open a repository that contains a .walkthroughs folder. Available tours appear in the Walkthroughs view.
  2. Run Walkthrough: Start Tour from the Command Palette (Ctrl+Shift+P).
  3. Use Ctrl+Alt+→ and Ctrl+Alt+← to move between steps.

Commands

CommandKeybindingDescription
Walkthrough: Start TourCtrl+Alt+WPick a tour from the current repository and begin at step 1.
Walkthrough: Record New TourCtrl+Alt+RStart recording. Each selection plus note becomes a step.
Walkthrough: Share TourNonePublish a tour to the team's onboarding path.

Extension Settings

{
  "walkthrough.autoStartForNewStarters": true,
  "walkthrough.showStepNumbers": true,
  "walkthrough.highlightStyle": "gutter",
  "walkthrough.maxStepsPerTour": 25
}

Requirements

  • Extension Library 2.0 or later (installed automatically).
  • Read access to the repository you are touring.
